Researched 2026-09-09. **[confirmed]**, multiple independent business-press sources (Variety,
Deadline, TechCrunch, Scopely's own press release), all converging on the same deal terms and
close date — this is a corporate-transaction fact, not a game-mechanics datamine, so the usual
"one report propagating through aggregators" caveat doesn't apply here.

Scopely acquired Niantic's **games division** (Pokémon GO, Pikmin Bloom, Monster Hunter Now, plus
Campfire/Wayfarer) for $3.5B; deal closed **2025-05-29**. Niantic itself did not disappear — it
spun off into **Niantic Spatial Inc**, a geospatial-AI company (still led by John Hanke), which
kept Ingress Prime and Peridot but **not** Pokémon GO. Studio leads (Kei Kawai, Ed Wu) continued
under Scopely.

**Practical consequence for future research passes**: `nianticlabs.com` news posts now 301-redirect
to `explore.scopely.com` (confirmed 2026-09-09 — and that specific redirect target 404's for at
least the one URL tested, so the redirect itself doesn't guarantee the content survived the
migration). `pokemongo.com`/`pokemongolive.com` still appear to be the live official blog, now
run by Scopely rather than Niantic. **Anything CLAUDE.md or a prior research note describes as "an
official Niantic blog post/patch note" from after 2025-05-29 should be understood as a Scopely
one** — the outranking-community-wikis tier still applies, but the entity name in front of it
needs updating going forward. Search queries hunting for "official" post-mid-2025 sourcing should
include "Scopely," not just "Niantic," or a real post may be missed.

No indication found that this affected the underlying combat mechanics/tuning discussed elsewhere
in this project's memory (raid boss energy, charge probability, etc.) — this is a corporate/org
fact, not a claim about anything changing in-game because of it.
